# hot-beans-web-portal
Training portal and job application site built with HTML, CSS, and JavaScript.

Hot Beans Web — Training & Job Portal

A multi-page website I built for a web development training portal that hosts course guides and job listings.

 What it does
- Multi-page layout covering courses, team profiles, and job applications.
- Live search on the job page to filter listings by keyword and dev stack.
- Interactive popups for team bios and job details.
- Progress bar on the application form that updates as you fill it out.

Tech stack
- HTML & CSS
- JavaScript
